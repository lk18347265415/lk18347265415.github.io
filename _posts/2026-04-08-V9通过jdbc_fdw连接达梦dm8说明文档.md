> **版本**: v1.0.0  
> **日期**: 2026-04-08

## 📋 1. 概述

### 1.1 背景介绍

随着国产数据库的快速发展，达梦数据库（DM8）作为国产数据库的代表产品，在政府和企业的信息化系统中得到了广泛应用。在实际业务场景中，经常需要实现 PostgreSQL 与达梦数据库之间的数据互通。jdbc_fdw（JDBC Foreign Data Wrapper）是 PostgreSQL 的外部数据包装器扩展，通过 JDBC 驱动可以连接任意支持 JDBC 的数据库，包括达梦 DM8。

本文档详细介绍在 **CentOS 7** 环境下如何搭建达梦 DM8 数据库、安装瀚高V9 及 jdbc_fdw 扩展，并实现两者之间的连接与数据操作。

### 1.2 技术架构

jdbc_fdw 是 PostgreSQL 的外部数据包装器（FDW）扩展，它通过 JDBC 接口与外部数据库进行通信。瀚高数据库管理系统V9 可以像访问本地表一样，通过 SQL 语句直接查询和操作达梦数据库中的数据，无需编写额外的数据同步程序。

### 1.3 组件说明

| 组件 | 说明 |
|------|------|
| **V9** | 瀚高数据库管理系统V9 |
| **jdbc_fdw 扩展** | PostgreSQL 外部数据包装器，负责 JDBC 连接管理 |
| **外部表** | PostgreSQL 中映射的达梦表定义 |
| **JDBC API** | Java 数据库连接标准接口 |
| **DM JDBC Driver** | 达梦数据库 JDBC 驱动（DmJdbcDriver8.jar） |
| **达梦 DM8** | 目标数据库，监听端口 5236 |

## 🏗️ 2. 达梦 DM8 环境搭建（CentOS 7）

### 2.1 系统要求

达梦 DM8 对运行环境的要求如下：

| 项目 | 要求 |
|------|------|
| CPU 架构 | x86_64 |
| 操作系统 | Linux（CentOS 7.x ） |
| 内存 | 最低 1GB，推荐 2GB 及以上 |
| 磁盘空间 | 最低 1GB，根据数据量规划 |
| JDK 版本 | JDK 8 或更高版本（可选） |

### 2.2 下载达梦 DM8 安装包

从达梦技术社区或官网获取 DM8 安装包和达梦JDBC驱动：

- 官方下载地址：https://www.dameng.com/download/index.html
- 选择 **dm8_xxxx_x86_CentOS7_64.iso** 版本（适用于 CentOS7.x）
- 下载达梦JDBC驱动(jdbc-xxxx.zip),选择对应dm8的jar包(DmJdbcDriver8.jar)

下载完成后，将 iso 镜像文件上传至服务器的 /opt 目录。

### 2.3 创建安装用户

达梦数据库要求使用非 root 用户安装。创建专用的 dmdba 用户：

```bash
# 创建用户组 dinstall
groupadd dinstall -g 2001

# 创建用户 dmdba
useradd  -G dinstall -m -d /home/dmdba -s /bin/bash -u 2001 dmdba

# 设置密码
passwd dmdba
```

### 2.4 检查并配置系统限制

检查当前用户的 ulimit 参数：

```bash
ulimit -a
```

建议配置参数（在 /etc/security/limits.conf 中添加）：

```bash
dmdba  soft      nice       0
dmdba  hard      nice       0
dmdba  soft      as         unlimited
dmdba  hard      as         unlimited
dmdba  soft      fsize      unlimited
dmdba  hard      fsize      unlimited
dmdba  soft      nproc      65536
dmdba  hard      nproc      65536
dmdba  soft      nofile     65536
dmdba  hard      nofile     65536
dmdba  soft      core       unlimited
dmdba  hard      core       unlimited
dmdba  soft      data       unlimited
dmdba  hard      data       unlimited
```

### 2.5 目录规划

1.可根据实际需求规划安装目录，本示例使用默认配置 DM 数据库安装在 /home/dmdba 文件夹下。

2.规划创建实例保存目录、归档保存目录、备份保存目录。

```bash
##实例保存目录
mkdir -p /dmdata/data 
##归档保存目录
mkdir -p /dmdata/arch
##备份保存目录
mkdir -p /dmdata/dmbak
```

修改目录权限

```bash
#将新建的路径目录权限的用户修改为 dmdba，用户组修改为 dinstall
chown -R dmdba:dinstall /dmdata/data
chown -R dmdba:dinstall /dmdata/arch
chown -R dmdba:dinstall /dmdata/dmbak

#给路径下的文件设置 755 权限
chmod -R 755 /dmdata/data
chmod -R 755 /dmdata/arch
chmod -R 755 /dmdata/dmbak
```



### 2.6 挂载镜像

切换到 root 用户，将 DM 数据库的 iso 安装包保存在任意位置，例如 /opt 目录下，执行如下命令挂载镜像：

```bash
cd  /opt
mount -o loop dm8_xxx_x86_CentOS7_64.iso /mnt
```

### 2.7 命令行安装

切换至 dmdba 用户下，在 /mnt 目录下使用命令行安装数据库程序，依次执行以下命令安装 DM 数据库。

```bash
su - dmdba
cd /mnt
```

执行如下命令进行安装。

```bash
./DMInstall.bin -i
```

按需求选择安装语言，没有 key 文件选择 "n"，时区按需求选择一般选择 “21”，安装类型选择“1”，安装目录按实际情况配置，这里示例使用默认安装位置。

### 2.8 执行安装后配置脚本

安装完成后，根据终端提示，以 root 用户执行配置脚本：

```bash
# 以 root 用户执行
su - root

# 执行配置脚本（路径根据实际安装位置）
/home/dmdba/dmdbms/script/root/root_installer.sh
```

### 2.9 初始化数据库实例

安装完成后，需要初始化数据库实例：

```bash
# 切换到 dmdba 用户
su - dmdba

# 进入达梦 bin 目录
cd /home/dmdba/dmdbms/bin

# 初始化数据库,设置初始化路径、sysdba和sysauditor密码
./dminit PATH=/xxx/xxx/data SYSDBA_PWD=XXX SYSAUDITOR_PWD=XXX
```

常用参数说明：

### 2.10 启动达梦服务

```bash
# 启动数据库服务（前台）
cd /home/dmdba/dmdbms/bin
./dmserver /xxx/xxx/data/DAMENG/dm.ini -noconsole &
```

### 2.11 验证安装

使用 disql 工具连接测试：

```bash
cd /home/dmdba/dmdbms/bin
./disql SYSDBA/SYSDBA@localhost:5236
```

默认 SYSDBA 密码为 SYSDBA，首次登录后建议修改密码。

连接成功后，执行以下命令验证：

```sql
-- 查看数据库版本
SELECT * FROM V$VERSION;

```

## 💻 4. jdbc_fdw 安装与配置（CentOS 7）

### 4.1 安装编译依赖

`jdbc_fdw` 旨在与 PostgreSQL 13 ~ 17 兼容。需要 Java 5 或更高版本（已确认的版本为 Java OpenJDK 1.8.0）。

```bash
# 安装编译工具和 JDK
sudo yum install -y gcc gcc-c++ make git java-1.8.0-openjdk-devel

# 检查 Java 环境
java -version
```

### 4.2 配置 JVM 软链接

jdbc_fdw 需要 JVM 库，需要创建软链接：

```bash
sudo ln -s /usr/lib/jvm/java-xxx-openjdk-xxx/lib/server/libjvm.so /usr/lib64/libjvm.so
```

### 4.3 编译安装 jdbc_fdw

从 GitHub 克隆源码并编译：

```bash
# 克隆源码
cd /tmp
git clone https://github.com/pgspider/jdbc_fdw.git
cd jdbc_fdw

# 配置 PostgreSQL 路径
export PG_CONFIG=/xxx/bin/pg_config

# 编译安装
make USE_PGXS=1	#编译可能报错，需要手动修改一个函数的参数。为jdbc_fdw中CreateTemplateTupleDesc函数新增一个默认参数false
make install USE_PGXS=1
```

### 4.3 创建 jdbc_fdw 扩展

```bash
# psql连接V9
psql -Uhighgo -p port_num

# 创建扩展
CREATE EXTENSION jdbc_fdw;

# 验证扩展
\dx
```

### 4.5 达梦 JDBC 驱动

请注意，必须指定驱动程序名称，jdbc_fdw 才能正常工作，将达梦JDBC驱动文件复制到指定路径：

```bash
sudo mkdir -p /opt/dmdbms/jdbc
sudo cp DmJdbcDriver.jar /opt/dmdbms/jdbc/
sudo chmod 644 /opt/dmdbms/jdbc/DmJdbcDriver.jar
```

## 📖 5. jdbc_fdw 连接达梦配置用例

### 5.1 创建外部服务器

```sql
-- 连接瀚高V9
psql -d highgo -p port_num

-- 创建外部服务器
CREATE SERVER dm_jdbc_srv
FOREIGN DATA WRAPPER jdbc_fdw
OPTIONS (
  drivername 'dm.jdbc.driver.DmDriver',
  url 'jdbc:dm://127.0.0.1:5236',
  jarfile '/opt/dmdbms/jdbc/DmJdbcDriver.jar'
);
```

参数说明：

- drivername：JDBC 驱动类名
- url：JDBC 连接 URL，格式为 jdbc:dm://主机:端口
- jarfile：DM JDBC 驱动 jar 包路径

### 5.2 创建用户映射

```sql
-- 创建用户映射
CREATE USER MAPPING FOR CURRENT_USER SERVER dm_jdbc_srv
OPTIONS (
    username 'SYSDBA',
    password 'your_password'
);
```

### 5.3 创建外部表

#### 5.3.1 手动创建外部表

```sql
-- 创建外部表（映射达梦的 emp 表）
CREATE FOREIGN TABLE dm_test (
    id int OPTIONS (column_name 'ID', key 'true'),
    name text OPTIONS (column_name 'NAME')
) SERVER dm_jdbc_srv
OPTIONS (
    table_name 'emp'
);
```

关键选项说明：

- column_name：指定达梦表中的实际列名
- key 'true'：标识主键列，用于 UPDATE/DELETE 操作
- table_name：达梦数据库中的实际表名,需要在达梦库中存在emp表

#### 5.3.2 在达梦数据库中创建表

```sql
create table emp(id int, name varchar2);
```

### 5.4 数据操作

#### 5.4.1 插入数据

```sql
-- 插入数据
INSERT INTO dm_test (id, name) VALUES (1, 'aa');
INSERT INTO dm_test (id, name) VALUES (2, 'bb');
INSERT INTO dm_test (id, name) VALUES (3, 'cc');
```

#### 5.4.2 查询数据

```sql
-- V9端查询达梦数据
SELECT * FROM dm_test;
```

#### 5.4.3 更新数据

```sql
-- 更新数据（需要主键）
UPDATE dm_test SET name = 'bob' WHERE id = 2;
```

#### 5.4.4 删除数据

```sql
-- 删除数据（需要主键）
DELETE FROM dm_test WHERE id = 1;
```

### 5.5 使用 jdbc_exec 函数直接执行 SQL

```sql
-- 直接在V9端执行 SQL
SELECT jdbc_exec('dm_jdbc_srv', 'SELECT * FROM EMP');

-- 带返回类型定义
SELECT * FROM jdbc_exec('dm_jdbc_srv', 'SELECT id, name FROM EMP') AS t(id int, name text);
```

## ⚠️ 6. 注意事项与限制

### 6.1 已知限制

 jdbc_fdw 以下功能暂不支持：

- RETURNING 子句
- GROUP BY 子句
- ORDER BY 子句
- 类型转换
- 事务控制
- 数组类型

### 6.2 主键要求

UPDATE 和 DELETE 操作需要在外部表中指定主键列，否则会报错：

```reStructuredText
ERROR:  no primary key column specified for foreign table
```
